# Changelog

## 1.0.1 — 2026-11-09

- Localized the distribution checkbox for Japanese and Simplified Chinese;
  English remains the fallback for other language settings.
- Added screenshots of the English, Japanese, and Simplified Chinese menus.
- Added prominent Steam Workshop installation links to both README translations.
- Distribution rules and saved container settings are unchanged.

### 日本語

- 振り分け設定のチェックボックスを日本語・簡体字中国語に対応しました。
  その他の言語設定では英語で表示されます。
- 英語・日本語・簡体字中国語の設定画面のスクリーンショットを追加しました。
- READMEの英語・日本語の使い方にSteamワークショップの導入リンクを追加しました。
- 振り分けルールと保存済みコンテナ設定に変更はありません。

## 1.0.0 — 2026-11-09

- Initial public release: an optional “Only put stolen goods” container filter.
- Works with existing categories, word filters, and distribution priorities.
- Supports carried containers, shared storage, and dumping destinations.
- Saves and copies the setting independently of vanilla flags.

### 日本語

- 初公開：コンテナに「盗品のみ入れる」フィルターを追加しました。
- 既存のカテゴリ・単語フィルター・振り分け優先度と併用できます。
- 携帯コンテナ・共有ストレージ・収納先の選択に対応しています。
- ゲーム本体のフラグとは独立して設定を保存・コピーします。
